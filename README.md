## Description

Configuren the networking on either ubuntu or FreeBSD machines.  the moduls supports
 * configuering server IP addresses
 * configuering dummy interfaces
 * adding standard and additional host entries
 * purging unmanaged host entries
 * configuering sysctl entries on linux systems
 * configurs the system to ignore all router advertisments for configuered interfaces
